# Amiscara Agents – Downloads

Installers of Amiscara Agents for Windows and Linux, a client for
[herdr](https://github.com/ogulcancelik/herdr) agents. The source lives in a
private repository; this one only carries the releases and the update
manifest (`latest.json`) the app checks.

## Install

Take the newest release under **Releases**:

- Windows: `Amiscara.Agents_<version>_x64-setup.exe` (or the `.msi`). The
  installer is not signed yet: SmartScreen asks once per version, choose
  "Weitere Informationen" and "Trotzdem ausführen".
- Linux: `.AppImage` (updates itself) or `.deb`.

The app looks for updates on start and offers to install them.
